    Component Test Specification / コンポーネント別テスト仕様書¶

    This is a review of assertions in the current test suite, not a claim that every listed test passed on every platform. It maps observable contracts to tests and records the conditions under which tests run. No public API or schema change is proposed. これは現行テストの assertion の照合結果です。全環境での成功を意味しません。 観測可能な契約とテストを対応付け、実行条件を示します。公開 API・schema の変更は提案しません。

    The generated API reference and Python docstrings define signatures, exceptions, units, and numerical behavior. Also see the compatibility policy, I/O contracts, and Frame extension guide. signature、例外、単位、数値挙動の正本は API reference と Python docstring です。互換性方針、 I/O 契約、Frame 拡張ガイドも参照してください。

    Reading the cases / ケースの読み方¶

    Each row specifies exactly one observable behavior with an ID, input or condition, expected result, existing test assertion, and coverage. File links lead to the test; the function name identifies the particular assertion to inspect. Confirmed / 確認済み means the named test asserts the stated result for the stated condition. Partial / 一部確認 means the cited assertion covers only part of the condition; the missing assertion follows the table. Unverified / 未確認 means no matching assertion was found in this review. A test file's existence alone is not evidence. 各行は ID と観測可能な振る舞いを一対一で対応させ、入力・条件、期待結果、既存テスト、充足状況を示します。 「確認済み」は記載条件の結果を assertion で確認した状態、「一部確認」は条件の一部のみ、 「未確認」は該当 assertion を見つけられなかった状態です。ファイルの存在だけでは充足としません。

    The TensorFlow GPU assertion runs only where a GPU is available; it is skipped in CPU-only environments. TensorFlow GPU の assertion は GPU がある環境でのみ実行され、CPU のみの環境では skip されます。
