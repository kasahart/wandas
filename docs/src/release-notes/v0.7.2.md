# Wandas 0.7.2

Wandas 0.7.2 adds a focused public measurement-level contract for linear
`ChannelFrame` channels.

Wandas 0.7.2では、linear `ChannelFrame` channel向けのfocusedな公開measurement-level
contractを追加します。

## Highlights / ハイライト

- `wd.LevelReference` exposes the numeric linear reference, its linear unit,
  the level unit, a canonical label, and scalar/array `to_level()` conversion.
- `frame.channels[index].level_reference` derives that value object from the
  channel's existing `unit` and `ref` metadata.
- SoundFile-backed reads explicitly mark canonical full-scale float channels as
  `FS` / reference 1. NumPy, CSV, and identity calibration remain generic.
- `LevelReference.to_level()`, FFT `.dB`, and STFT `.dB` share one private
  log-domain amplitude-level implementation with a `1e-12` ratio floor.

- `wd.LevelReference`は、linear reference値、linear unit、level unit、canonical
  label、scalar／array向け`to_level()`変換を公開します。
- `frame.channels[index].level_reference`は、既存channelの`unit`と`ref`
  metadataから値objectを導出します。
- SoundFile-backed readはcanonical full-scale float channelを`FS`／reference 1
  として明示します。NumPy、CSV、identity calibrationはgenericなままです。
- `LevelReference.to_level()`、FFTの`.dB`、STFTの`.dB`は、ratio floor
  `1e-12`を持つ1つのprivate log-domain実装を共有します。

WDF remains version 0.4 and Recipe schema and operation versions are unchanged.
The public descriptor is rederived only for linear Frames from existing channel
metadata. This release does not add structured level-domain persistence, a
level-unit parser, scalar peak/level convenience properties, or new temporal
level semantics.

WDFはversion 0.4のままで、Recipe schemaとoperation versionも変更しません。公開descriptorは
linear Frameの既存channel metadataからのみ再導出されます。このreleaseではstructuredな
level-domain永続化、level-unit parser、scalar peak／level convenience property、新しいtemporal
level意味論を追加しません。

See [Convert Linear Measurements to Reference-Relative Levels](../how-to/measurement-levels.md)
and the [Core API Reference](../api/core.md).

## Correctness fixes / 正しさの修正

- CSV channel subsets and reordering keep inferred labels aligned with sample
  values. Explicit replacement labels still describe the selected output channels.
- CSV rates retain fractional values, including rates below 1 Hz. Only roundoff
  near a positive integer rate is snapped to that integer. Invalid or insufficient
  timestamps fail with a sampling-rate error before sample indexing.
- Floating-point WAV export always uses IEEE FLOAT (float32 precision), including
  calibrated amplitudes outside `[-1, 1]`. It no longer silently switches those
  values to PCM and clips them. Integer export keeps the format's default subtype.
- `SpectralFrame.n_fft` / `window` and `SpectrogramFrame.n_fft` / `hop_length` /
  `win_length` / `window` are read-only. Direct assignments now raise
  `AttributeError`: they previously changed axes without transforming samples or
  updating lineage. To change analysis settings, rerun `fft()` or `stft()` on the
  source Frame. This immediately enforces the existing immutable-Frame contract.
- Recipe extraction and derived operation history use iterative traversal, so
  long valid processing chains do not depend on Python's recursion limit. Input
  discovery order, shared nodes, operation versions, and schema remain unchanged.

CSV のチャンネル選択・並べ替えでラベルと値の対応を保持し、非整数・1 Hz 未満の
sampling rate も保持します。無効な時刻列はサンプル添字の計算前に明示的に拒否します。
浮動小数点の WAV 保存は振幅にかかわらず FLOAT を使用し、範囲外振幅の暗黙の切り詰めを
防ぎます（精度は float32）。FFT/STFT の解析条件への直接代入は `AttributeError` となるため、
条件変更は元の Frame から解析し直してください。Recipe と派生履歴の走査は再帰を使わず、
長い処理チェーンでも既存の順序・共有ノード・schema を保持します。
