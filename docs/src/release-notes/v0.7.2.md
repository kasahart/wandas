# Wandas 0.7.2

Wandas 0.7.2 adds one channel-aware measurement-level contract. Linear RMS and
peak amplitudes, reference-relative scalar levels, and FFT/STFT `.dB` now share
the channel calibration reference and one documented amplitude-ratio floor.

Wandas 0.7.2では、channel-awareなmeasurement-level contractを追加します。線形RMS／
peak振幅、reference-relativeなscalar level、FFT／STFTの`.dB`は、channel calibrationの
referenceと文書化された1つのamplitude-ratio floorを共有します。

## Highlights / ハイライト

- `ChannelMetadata.level_reference` exposes structured `unit`,
  `reference_value`, `reference_unit`, and canonical `label` fields, plus
  scalar/array `to_level()` conversion for already-calibrated amplitudes.
- `ChannelFrame.rms_level` and `peak_level` add eager per-channel level
  reductions while `rms` and the new `peak` remain linear.
- SoundFile-backed `wd.read()` results explicitly use `FS` / reference 1 and
  therefore derive dBFS. NumPy and CSV input remain generic; identity
  calibration alone is never interpreted as full scale.
- RMS, peak, FFT, and STFT amplitude levels floor the amplitude/reference ratio
  at `1e-12`, giving `-240 dB` for zero.

- `ChannelMetadata.level_reference`は、構造化された`unit`、`reference_value`、
  `reference_unit`、canonicalな`label`と、校正済み振幅用のscalar／array
  `to_level()`変換を公開します。
- `ChannelFrame.rms_level`と`peak_level`はchannelごとのeager level reductionを追加し、
  `rms`と新しい`peak`は線形値のままです。
- SoundFileを使う`wd.read()`結果は`FS`／reference 1を明示し、dBFSを導出します。
  NumPy／CSV入力はgenericなままで、identity calibrationだけをfull scaleと解釈しません。
- RMS、peak、FFT、STFTのamplitude levelは振幅／reference比を`1e-12`でfloorし、
  zeroを`-240 dB`として返します。

## Compatibility / 互換性

WDF remains format version 0.4 and Recipe JSON remains schema version 2. The
measurement descriptor is derived from the existing `unit` and `ref` fields, so
no duplicate persisted state or schema migration is introduced. Existing
`sound_level(dB=True)` power-detector numerics and its Recipe versions are
unchanged.

The channel unit labels produced by `rms_trend(dB=True)` and
`sound_level(dB=True)` are normalized to the same human-readable canonical form
as `LevelReference.label`. This display-metadata normalization does not change
their numerical results, and the structured input-side
`LevelReference.reference_value` is not rounded.

WDFはformat version 0.4、Recipe JSONはschema version 2のままです。measurement
descriptorは既存の`unit`と`ref`から導出するため、重複する永続stateやschema migrationは
追加しません。既存の`sound_level(dB=True)` power-detector numericsとRecipe versionも
変更しません。

`rms_trend(dB=True)`と`sound_level(dB=True)`が生成するchannel unit labelは、
`LevelReference.label`と同じ読みやすいcanonical表記へ正規化されます。この表示metadataの
正規化によって数値結果は変わらず、構造化された入力側の
`LevelReference.reference_value`も丸められません。

Wandas does not reinterpret an empty-unit channel in an older WDF as full
scale: the persisted metadata is ambiguous and remains generic `dB re 1 input
unit`. If the recording is known independently to contain canonical full-scale
audio, migrate it explicitly after loading, then save the replacement Frame:

```python
import wandas as wd

legacy = wd.load("legacy.wdf")
migrated = legacy.with_calibration(
    [
        wd.ChannelCalibration(
            factor=channel.calibration.factor,
            unit="FS",
            ref=1.0,
        )
        for channel in legacy.channels
    ]
)
migrated.save("full-scale.wdf")
```

過去のWDFにある空unit channelを、Wandasがfull scaleへ自動的に読み替えることはありません。
永続化されたmetadataだけでは意味を確定できないため、`dB re 1 input unit`のgenericな
扱いを維持します。収録値がcanonical full-scale audioだと別途確認できている場合に限り、
上記のようにload後の各channelへ`unit="FS"`／`ref=1`を明示し、置換後のFrameを保存して
ください。
