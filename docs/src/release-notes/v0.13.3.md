# Wandas 0.13.3

Wandas 0.13.3 makes reading part of a cached Frame cheap: a slice of a
`cache()` result copies only the selected samples instead of every channel.

Wandas 0.13.3では、キャッシュしたFrameの一部を読むときの負担が小さくなりました。`cache()`の結果の
一部を読むと、全チャンネルではなく選んだサンプルだけをコピーします。

## Highlights / 主な変更

- Reading one slice of a cached Frame, such as `frame.cache()[:, a:b].data`,
  copies only that slice. Before, every read first copied the whole cached
  channel blocks. Values do not change, and the arrays you get back are still
  writable copies that do not change the cache.
  `frame.cache()[:, a:b].data`のようにキャッシュしたFrameの一部を読むと、その部分だけをコピーします。
  これまでは読むたびに、まずキャッシュしたチャンネルのブロック全体をコピーしていました。値は変わらず、
  返る配列は今までどおり書き込み可能なコピーで、書き換えてもキャッシュは変わりません。

## Changed / 変更

- The samples kept by `cache()` are read-only, and operations on a cached
  Frame receive read-only views of them
  ([#659](https://github.com/kasahart/wandas/issues/659)). Built-in
  operations already return new arrays and are not affected. A custom
  operation that writes into its input block now raises `ValueError`
  (assignment destination is read-only) instead of silently working on a copy;
  return a new array instead, for example `x = x.copy()` before writing.
  `cache()`が保持するサンプルは読み取り専用になり、キャッシュしたFrameへの操作は読み取り専用の
  ビューを受け取ります。組み込みの操作は新しい配列を返すので影響はありません。入力のブロックに
  書き込む独自の操作は、黙ってコピーを書き換える代わりに`ValueError`
  （assignment destination is read-only）を出すようになりました。書き込む前に`x = x.copy()`とするなど、
  新しい配列を返してください。

## Compatibility and migration / 互換性と移行

Computed values, Recipe schemas, operation versions and WDF formats do not
change. Arrays returned by `data`, slices and `np.asarray()` stay writable.
Only custom operations that write into their input on a cached Frame need a
change.

計算結果・Recipeのスキーマ・操作のversion・WDFの形式は変わりません。`data`・スライス・`np.asarray()`が
返す配列は今までどおり書き込めます。キャッシュしたFrameで入力に書き込む独自の操作だけ対応が必要です。

| Affected surface or artifact | Classification | Deprecation start | Replacement or migration | Removal/change version | Exception reason and decision link |
| --- | --- | --- | --- | --- | --- |
| Input blocks that operations receive from a `cache()` result | Stable, behavior change for custom operations that write into their input | None | Return a new array instead of writing into the input (for example `x = x.copy()` first) | 0.13.3 | Writable copies of every block made each slice read copy the whole cache; [#660](https://github.com/kasahart/wandas/pull/660) |

| 影響する機能・データ | 分類 | 非推奨の開始 | 代替・移行方法 | 変更バージョン | 例外の理由と判断のリンク |
| --- | --- | --- | --- | --- | --- |
| `cache()`の結果から操作が受け取る入力ブロック | Stable、入力に書き込む独自の操作に対する挙動の変更 | なし | 入力に書き込まず新しい配列を返してください（先に`x = x.copy()`とするなど） | 0.13.3 | ブロックごとに書き込み可能なコピーを作ると、一部を読むだけでキャッシュ全体をコピーしていたため。[#660](https://github.com/kasahart/wandas/pull/660) |
