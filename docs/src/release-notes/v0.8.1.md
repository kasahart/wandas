# Wandas 0.8.1

Wandas 0.8.1 adds header-only audio inspection and authoritative physical STFT
frame centers, so applications can reject oversized recordings before building
a Frame and stop reconstructing the numerical engine's clock themselves.

## Highlights / 主な変更

- `wd.inspect()` reads built-in local audio headers without PCM decoding or a
  Dask graph. Borrowed seekable streams retain their position and ownership.
- `frame_center_times` exposes channel-aware physical centers, including negative
  padding and source offsets. `frame_time_origin` is retained through supported
  transforms and accepted by `SpectrogramFrame.from_numpy()`.
- Unknown origins raise explicitly instead of being inferred from history.
- Existing `times`, `source_times`, plot, ISTFT, `get_frame_at`, Recipe schemas and
  operation versions retain their contracts.

- [#466: header-only inspection and physical frame centers](https://github.com/kasahart/wandas/pull/466).

## Compatibility and migration

| Affected surface or artifact | Classification | Deprecation start | Replacement or migration | Removal/change version | Exception reason and decision link |
| --- | --- | --- | --- | --- | --- |
| `inspect`, `frame_center_times`, explicit NumPy-factory origin | Stable, additive | Not applicable | Opt in to the new API; existing time axes are unchanged | 0.8.1 | No removal; [#466](https://github.com/kasahart/wandas/pull/466) |
| Known-origin Spectrogram/Cepstrogram WDF output | Serialized, additive schema 0.5 | Not applicable | Upgrade producing and reading environments to 0.8.1+ before exchanging 0.5 artifacts | 0.8.1 | Existing 0.4 read semantics preserved; [#466](https://github.com/kasahart/wandas/pull/466) |

Known-origin SpectrogramFrame/CepstrogramFrame results now save as WDF 0.5.
Other supported results, including unknown origins, retain WDF 0.4. Released
0.8.0 and older readers explicitly reject 0.5: coordinate producer/consumer
upgrades before exchanging these artifacts.

The 0.8.1 reader still loads WDF 0.4 without changing its stored data or legacy
axes. Physical centers stay unknown for old artifacts. Recompute the STFT from
original audio or supply a known origin from the original processing settings;
do not infer it from display history. Existing 0.4 files need no bulk migration.

0.8.1では既知起点のSpectrogram/Cepstrogram保存にWDF 0.5を使います。
旧readerは0.5を拒否するため、作成側・読込側を0.8.1以降へ揃えてください。
既存0.4のデータ・従来の軸は変わらず、全ファイルの一括移行は不要です。
