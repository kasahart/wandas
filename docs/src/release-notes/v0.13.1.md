# Wandas 0.13.1

Wandas 0.13.1 lets a `ChannelFrame` subclass load files as itself, so an
extension that adds methods to `ChannelFrame` can call `read_wav()` directly.

Wandas 0.13.1では、`ChannelFrame`のサブクラスがファイルを自分のクラスのまま読み込めるようになりました。
`ChannelFrame`にメソッドを足す拡張から、`read_wav()`を直接呼べます。

## Highlights / 主な変更

- `from_numpy()`, `from_file()`, `read_wav()` and `read_csv()` called on a
  `ChannelFrame` subclass return that subclass, and `add_channel()`,
  `remove_channel()` and `concat_frame()` keep it.
  `ChannelFrame`のサブクラスで`from_numpy()`・`from_file()`・`read_wav()`・`read_csv()`を呼ぶと
  そのサブクラスを返し、`add_channel()`・`remove_channel()`・`concat_frame()`もサブクラスを保ちます。

## Changes / 変更一覧

- [#644: keep `ChannelFrame` subclasses through loaders and channel updates](https://github.com/kasahart/wandas/pull/644) / 読み込みとチャンネル操作で`ChannelFrame`のサブクラスを保つ

## Compatibility and migration / 互換性と移行

Computed values, Recipe schemas, operation versions and WDF formats do not
change. Calls on `ChannelFrame` itself return `ChannelFrame` as before. WDF
`save()` still supports only the built-in Frame classes.

計算結果・Recipeのスキーマ・操作のversion・WDFの形式は変わりません。`ChannelFrame`自体で呼んだ場合は
今までどおり`ChannelFrame`を返します。WDFの`save()`は引き続き組み込みのFrameクラスだけに対応します。
