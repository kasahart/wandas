# Processing Module / 処理モジュール

The `wandas.processing` module contains audio operations for temporal, spectral,
cepstral, statistical, filter, and effect processing. Each operation's numerical
contract is generated from its Google-style docstring.

`wandas.processing`は時間領域、スペクトル、ケプストラム、統計、filter、effectのaudio
operationを提供します。各operationの数値契約はGoogle style docstringから生成されます。
